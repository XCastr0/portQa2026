# Portfólio QA Automation – Luana Beatriz 🧪🚀

Este repositório contém o **código-fonte do meu portfólio profissional**, onde apresento minha experiência como **QA Automation**, com foco em **automação de testes web**, **validação de releases**, **CI/CD** e **qualidade de software**.

O portfólio foi desenvolvido para demonstrar, de forma clara e prática, minhas **habilidades técnicas**, **projetos em automação** e **experiência profissional em QA**.

---

## 👩‍💻 Sobre mim

Sou **QA Automation**, com experiência em testes de aplicações web atuando desde a análise de requisitos até a entrega em produção.  
Tenho forte atuação em:

- Automação de testes E2E e regressão
- Validação e gerenciamento de testes de release
- Integração de testes em pipelines CI/CD
- Testes funcionais (UI e API)
- Apoio e mentoria para outros QAs

Atualmente atuo na **SINART Organização**, contribuindo para entregas mais estáveis, seguras e confiáveis.
